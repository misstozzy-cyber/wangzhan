# TYRIA LIGHTING Official Website

> **Specialized LED Strip & Silicone Neon Flex Manufacturer — Engineered for Lighting Designers.**  
> Established in 2012 in Shenzhen, China. Operating across two specialized manufacturing bases (11,000 m² total) with 6 silicone co-extrusion lines, in-house SMD packaging, and CNAS-grade photometric laboratory.

---

## 🌟 Key Highlights & Engineering Features

- **1:1 Architectural Profile Atlas**: Over 50 true-scale silicone LED neon cross-sections rendered to physical scale (`1mm = 4.2px`) with dynamic emitting surfaces and a draggable millimeter caliper filter.
- **Global Kelvin Engine (1600K–12000K)**: Real-time Tanner Helland color-temperature simulation driving all glowing SVGs, cross-sections, and scene lighting.
- **Interactive Bend Lab**: Live cubic Bézier curvature simulator comparing Top View (TV), Side View (SV), and 3D dual-bend radii against real factory minimum bending diameter ratings (down to R15mm).
- **Anti-Glare UGR < 19 Optical Control**: Interactive before/after split slider illustrating direct shielding and cut-off angle control for EN 12464-1 compliance.
- **Light the Building**: Architectural night illumination simulator with interactive zone selection across Facade, Parapet, Atrium, Cove, Office, and IP68 Pool decks.
- **Spec Finder Database**: High-density parametric search and filtering across 115+ models with 4-model side-by-side comparison drawer and instant CSV export.
- **Designer Hub**: Centralized access to 259 `.IES` and `.LDT` photometric distribution files, integrating sphere reports, and 6 master 2026 product catalogues.
- **B2B RFQ & Sample Basket**: Persistent multi-model quotation builder supporting structured submissions, WhatsApp dispatch, and direct email triggers.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite 6
- **Styling**: Tailwind CSS + Custom CSS Variables for real-time photometric glow
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Data Pipeline**: Python (`PyMuPDF` + `Pillow`) automated extraction from factory specification PDFs

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/zzyxiangnian-star/-.git

# Enter directory
cd -

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the website locally.

### Production Build

```bash
npm run build
```

The production output will be generated in `dist/`.
